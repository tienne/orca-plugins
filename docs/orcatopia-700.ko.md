# Orcatopia 바다·강 100종과 총 700종 확장

[English](orcatopia-700.md) · 한국어

## 범위와 실제 수량

기존 600종을 보존하고 바다 50종과 강 50종을 추가한 미배포 소스 변경입니다. **일반 700종·일반/+ 1,400종·수집 국가 153곳**을 제공합니다. 지형은 **육지 504·바다 72·강 91·육지와 바다 겸용 33종**입니다. 국가명은 수집 분류입니다. 맨섬·마셜 제도·키리바시·바하마·스웨덴·가이아나·파라과이 7개 분류가 늘었습니다. 한국은 기존 육지 14종을 유지하고 해상 등대 3종과 강 다리 2종을 더해 총 19종이 됩니다.

사용자가 선택한 1번 안에 따라 기존 수상 도감의 분포와 장소 특징을 보고 등급을 배분했으며 신규 바다·강 모두 네 등급을 포함합니다. 알아보기 쉬운 토목·생태 구조를 보물에, 큰 해양 보호 경관과 대표 교량·산업 시설·폭포를 경이에 배치했습니다. 피닉스 제도와 파나마 운하는 불가사의로 선정했습니다. 이는 게임 수집 등급이며 기존 600종 등급은 그대로입니다. 추첨 확률은 **70/23/6/1%**를 유지합니다. 모든 테마를 해금한 뒤 개별 장소의 확률은 등급별 약 0.21021% / 0.07958% / 0.09375% / 0.07143%이며, 해금 전에는 각 등급 안에서 열린 테마 후보만 뽑습니다.

장식은 **총 2,139종**으로 테마 1,426·무료 기본 5·정원 중심 4·합성 별빛 기념비 700·관광 건물 4종입니다. 물 전용은 **196테마×2=392종**입니다. 일반 첫 발견 선물 ID는 713개, 첫 합성 선물 ID는 700개입니다. 기존 수상 호환 13종의 추가 장식도 유지합니다. 새 바다 세트는 장면에 맞춰 산호나 항로 부표를 첫 선물로, 강 세트는 연꽃밭·뗏목·물레방아를 사용합니다. 정원 장식은 자체 제작 가상 모형입니다.

## 선정·분류 근거와 출처

바다는 외해 암초·섬의 등대, 산호초·석호·해양보호구역·침몰 유산과 조수가 드나드는 항만의 다리를 선정했습니다. 강은 강을 건너는 다리, 운하·수로·승강 시설과 강물의 폭포·급류를 선정했습니다. 게임의 강 분류에는 해수면 운하도 포함합니다. 섬과 등대의 바다는 지지 암초·섬 주변 수면을 함께 표현하는 미니어처 배치 기준입니다.

700종의 ID·정규화한 이름을 비교하고 별칭과 포함 관계를 검토했습니다. 타워브리지와 런던탑, 시드니 하버브리지와 오페라하우스는 각각 별개 구조물입니다. 카를교·베키오 다리·펄트니 다리는 기존 프라하 천문시계·피렌체 대성당·배스 로마 목욕장과 구별합니다. 알칸타라는 톨레도의 동명 다리와 다른 엑스트레마두라 타호강의 로마 다리입니다. 아포리프는 네그로스 근처 아포섬과 다른 민도로 서쪽 산호초입니다. 기존 베네치아·그레이트배리어리프·하롱베이·갈라파고스·코모도 안의 하위 장소는 추가 수량 후보에서 제외했습니다. 새 비키니·피닉스·나메나 등 한 장소 안의 구성 요소도 따로 세지 않습니다.

아래 100개 기관·시설의 원문을 이름·국가·수상 연결과 직접 작성한 한영 소개의 근거로 삼았습니다. 등대 운영기관, 유네스코, 공원 관리청, 국가·도시 관광청과 다리 설계사의 자료를 사용했습니다. `scripts/data/orcatopia-water-100-sources.json`에 조회일, 직접 조회한 원문의 체크섬, 접근 방식, 좌표와 별도 좌표 출처를 기록했습니다. 2026-11-17 기준 **86개 원문은 직접 읽었고 14개는 직접 요청 오류·봇 제한으로 기관 원문의 검색 색인에서 확인했습니다.** 색인으로 확인한 항목에 원문 체크섬을 지어 넣지 않았습니다.

좌표는 세계지도의 대표점입니다. **39곳**은 운영기관·관광기관 지도 메타데이터, 유네스코 데이터셋, 람사르 좌표와 공식 제출 경계를 사용했고, **61곳**은 별도 링크의 위키데이터·위키미디어·오픈스트리트맵 좌표로 대조했습니다. 뉴질랜드 운영기관의 등대 위치는 분 단위로 반올림되어 있습니다. 넓은 해양공원과 긴 운하는 전체 구역이나 특정 구성 요소의 대표점일 수 있으며, 나메나는 주변 보호구역을 나타내는 섬의 대표점을 사용합니다. 현장 조사와 정밀 경계 측량은 하지 않았습니다. 하우라 다리의 위키데이터 후보에는 경도 부호가 잘못된 값이 있어 채택하지 않았고, 일반 검색이 다른 지형을 가리킨 굴포스는 폭포 객체로 다시 대조했습니다. 베키오·펄트니의 관광 지도 중심도 실제 구조물의 보조 좌표로 바꿨습니다. 이 자료는 실행 중 요청하지 않습니다.

## 연결 구조와 보존 계약

`catalog-700.json`에 새 기록·한국어 번역·수상형·구조 비례·장면 구성을 모았습니다. `sync-orcatopia-water-700.mjs`는 커밋된 기존 600종 기록·번역 해시를 검사한 뒤 실행용 도감을 동기화합니다. 기존 도감 생성기도 앞선 확장을 만든 뒤 이 동기화를 적용해 새 100종을 유지합니다. 그림과 장면은 로컬 번들에 포함하며 배치·수집·지도·검색·첫 발견 선물·합성 기념비는 기존의 도감 기반 규칙을 사용합니다.

기존 ID·수량·배치·선물·합성·열린 땅·저장 키·v8 백업을 보존합니다. 도감만 읽어 랜드마크·탐험권·재료를 지급하지 않습니다. 누적 고유 발견 12/25종에서 강·바다를 해금하며 테마별 첫 탐험은 기존 탐험권 1장을 씁니다. 잠긴 테마는 일반 추첨에서 제외하고 확장된 보장 탐험 후보도 네 등급을 모두 포함합니다. 빈 등급의 가중치 재조정도 계속 검사합니다. 관광은 배치한 고유 기본 ID로 계산해 중복·일반/+ 집계와 오프라인 상한·수입률·특수 건물 가격을 유지합니다. 관광 기능이나 호스트 권한을 추가하지 않습니다.

## 검증과 검토 산출물

Nx 단위 검사는 700종 전체, 기존 600종 기록·번역 해시와 기준 커밋의 일반/+ 그림·장면 전체 1,200개 해시, 식별자·그림 인스턴스 접두사를 뺀 도형 중복, 장면 구성 중복, 일반/+ 보존, 배치와 장식 지형, 해금·보장 추첨의 모든 등급 후보, 합성·선물 보존, 이관·백업·복원과 관광을 검사합니다. 브라우저 fixture로 한영 설명·출처·합성·700장 지연 렌더링·화면 밖 정지·동작 줄이기·지도 점·저장 보존을 검사합니다. SVG 경로 길이 검사도 추가해 문자열만 존재하고 그려지지 않는 경로를 잡습니다.

`catalog-700.spec.ts`는 20종씩 나눈 영어 **DEMO** 검수표 JPEG 5장을 생성합니다. 미리보기와 바다·강 배경의 40픽셀 그림을 함께 보며 결과는 커밋하지 않는 test-results 아래에 둡니다. 실제 사용자 저장은 사용하지 않습니다. 기존 600종 장면·데이터를 유지하고 새 일반/+도 기존 추가 효과와 동작 제어를 따릅니다. `pnpm nx run landmark-island:typecheck`, `:test`, `:build`, `:ui-test`와 빌드 아티팩트 검증을 실행합니다. 생성 빌드와 검수 스크린샷은 개발 커밋에서 제외합니다. 패키징·CLI 검증은 로컬 근거이며 공개 디렉터리 등록·실행 승인·릴리스·실제 저장 주입은 범위 밖입니다.
